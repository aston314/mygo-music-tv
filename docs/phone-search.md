# 扫码搜索

资源搜索与插件市场的搜索栏均提供“扫码输入”。保留原来的键盘输入与搜索按钮；
电视弹窗显示当前搜索范围、二维码、连接标识和真实的五分钟有效期。
手机扫码后打开 My Music+ 输入页，输入关键词并点击“搜索”，电视自动执行对应
搜索、关闭弹窗并定位结果，无需再在电视确认。

- 资源搜索沿用当前音乐源与歌曲／专辑／歌手／歌单／播客分类，不自动播放。
- 插件搜索沿用全部／已安装／可更新筛选，不安装插件、不切换音乐源。
- 空结果提供修改关键词；资源请求失败保留收到的文字并提供重试。
- 手机页跟随打开二维码时的深浅主题与简繁中文。

扫码弹窗默认聚焦“取消”，方向键只在“取消／刷新二维码”按钮之间移动。
等待、已连接等文字仅作为状态提示朗读，不加入操作焦点；刷新、失败和过期
保留当前按钮焦点。返回或取消关闭弹窗后回到原“扫码输入”入口。

## 网络与生命周期

电视和手机需要处于可互通的同一局域网；电视有线连接、手机 Wi-Fi 也可使用。
Android 通过当前 Wi-Fi／以太网的 LinkProperties 提供私有 IPv4 地址提示，
Go 在其它宿主或提示不可用时从网络接口发现地址。未找到地址会提供重试，
原搜索输入仍然可用。IPv6-only 网络、路由器客户端隔离及宿主防火墙放行
不在本次实现范围内。

Go 只在打开扫码时启动独立的临时 LAN 端口。应用 API 继续绑定 127.0.0.1，
手机端口只允许输入页、其静态资源和单一输入会话接口，不代理应用 API、账号、
音乐源、播放或安装请求。随机手机令牌位于二维码 URL 的 fragment，通过
Authorization 请求头使用，与本机应用令牌和会话所有者 ID 分离。

每次会话仅接受一次、一个目标字段的非空关键词，最多 200 个 Unicode 字符；
拒绝错误目标、重复、过期、超长、控制字符、畸形 JSON 与跨站请求。文字仅在
内存流转，不写日志。连接标识仅用于比对手机与电视，不是登录码或授权密码。

返回、取消、刷新、切页和后台事件撤销会话；刷新后旧二维码不能提交。
异步回调同时检查页面、音乐源、分类及会话代次，迟到响应不触发搜索。
Android 的后台清理带时间界限，延迟执行不会撤销恢复前台后新开的会话。
电视每约 900ms 查询一次状态；所有者超过 30 秒未查询时服务自动失效，手机
查询不能续期。总寿命最多五分钟，关闭或失效后临时监听器停止。

## 本机所有者接口

以下接口沿用现有应用认证与 Origin 校验：

- `POST /api/input-session`：目标、展示范围、初始文字、主题、语言与可选 LAN 地址。
- `GET /api/input-session?id=…`：查询状态和已提交的值，维持所有者短租约。
- `GET /api/input-session/qr?id=…`：生成 PNG 二维码。
- `DELETE /api/input-session?id=…`：撤销指定会话。
- `DELETE /api/input-session?before=…`：宿主后台事件撤销该时间前创建的会话。

手机只使用临时端口的 `GET/POST /input/session`。响应不返回所有者 ID、
本机 API 令牌或完整二维码地址；POST 固定提交 `{target,value}`。

## 验证范围

`core/internal/phoneinput/broker_test.go` 与服务集成测试覆盖真实临时监听器、
认证隔离、一次性提交、并发、失效、刷新、租约和延迟后台清理。
`tests/phone-input.spec.cjs` 通过桌面和 Android 类 WebView 上下文检查扫码
搜索、结果焦点、错误重试、遥控器路径、直接键盘输入和迟到回调。
布局覆盖 960×540、1280×720、1920×1080、1280×800，及两套主题／语言。

浏览器自动化中的手机页面连接本机真实 Go 临时监听器，将二维码地址的主机
替换为 127.0.0.1；这属于本机浏览器测试。随后已通过现有 CI 构建签名测试包
`0.1.4-test.5 / 9` 并覆盖安装到 117，保留原有数据；电脑移动页面直接连接
电视真实 LAN 地址，完成资源／插件搜索、焦点、刷新与后台恢复验收。
实体手机相机扫码尚未验证。具体构建、设备结果与限制见
[SHIELD 测试包验收](tv-device-verification-v0.1.4-test.5.md)。测试包保存在私有
草稿 Release，公开更新渠道保持不变。
