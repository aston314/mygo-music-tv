# 卡片文字与海报焦点

## 显示规则

- 海报卡片、插件卡片及推荐大卡的标题完整换行，不限制行数，也不添加省略号。
- 卡片副标题保留单行，超出宽度时显示省略号。
- 歌单卡片只显示名称与插件提供的 `trackCount`，例如 `43 首`；不显示创建者或描述。缺失、负数、非整数等无效数量不显示。明确提供的 `0` 显示为 `0 首`。
- 没有有效副标题时不渲染空文字行，也不再使用“打开聆听”占位。
- 海报卡片仍然只有一个可操作焦点，点击文字也能打开详情。视觉焦点只围绕海报：4px 外框与图片之间留出 6px 空隙，保留图片圆角；不框住文字，不缩放卡片。
- 插件卡片没有海报，沿用整张卡片的焦点。
