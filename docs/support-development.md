# 支持开发

2026-11-15，用户决定启用此前暂缓的自愿支持功能。

右上角账号图标右侧使用跟随主题色的咖啡杯 SVG，与账号入口同时显示或隐藏；插件市场、设置、歌词页、无音乐源或音乐源没有账号能力时均隐藏。未登录但仍显示账号入口时，也显示支持入口。弹窗正文只有：

> 自愿支持 My Music+ 的开发与维护。支持与否不影响应用功能，也不提供任何音乐平台会员或额外播放权限。

弹窗不增加可见标题、金额、支付按钮或其它说明。右上角为关闭图标；二维码图片保留原有图中文字。繁体界面使用单独的 `zh-TW.js` 对应翻译。

二维码资源按用户指定，从红果短剧 Android TV 项目原样复制：

- 来源：`hongguo-android-tv-channel/core/cmd/hongguotv/ui/images/`。
- 本项目：`ui/images/support-wechat.png`、`ui/images/support-alipay.png`。
- 微信 SHA256：`99e3d6f84e6ff9e64626b15e5385a76ac182ee2a83dca74cb78c63257d60a403`。
- 支付宝 SHA256：`d754a25b169b530736593b0babe0f024a4026ca93c15e82831da8e01fb9a1e63`。

PNG 不裁剪、不改色，以原始比例展示，随 `ui.Files` 嵌入核心，从本机静态资源加载。二维码无需访问远程图片服务，不接入支付 SDK、不读取收款结果、不改变功能或播放权限。

遥控器默认焦点在微信二维码，左右切换，确认放大；关闭大图恢复原二维码焦点，关闭弹窗恢复支持入口。关闭图标保留在 TV／桌面上；不因 TV 隐藏纯返回按钮的规则而丢失关闭操作。沿用通用弹窗焦点限制和主题焦点样式。

浏览器专项检查覆盖：深浅主题、桌面与 Android 类 WebView 上下文、多种视口下的完整图片和弹窗、精确文案、简繁翻译、嵌套放大返回、无插件状态及播放状态保留；文件 SHA256 与 PNG 响应类型亦验证。

本地预览复用已存在的核心二进制并代理当前 UI／PNG；未在本机编译。GitHub CI 验证实际 Go 嵌入与 Android 构建，117 真机安装／手机扫码仍需后续验收。
