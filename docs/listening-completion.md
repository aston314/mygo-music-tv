# 聆听功能补齐

本轮沿用 MyGo Music 的 Source 协议与现有 Java / Go / WebView 边界，补齐播放恢复、音质、歌单编辑、电台续播和播客分页。仅处理在线来源，不引入本地曲库。插件协议依据仓库中的 `core/internal/music`、`core/internal/plugin/source.go` 及上游审计副本（commit `3ef2124`），浏览器验证使用确定性插件和拦截响应，不向真实账号写入歌单。

## 播放恢复与音质

Go 将队列元数据、条目 ID、当前索引、进度、时长、随机历史、待播优先项和电台信息保存到数据目录的 `playback-session.json`。playing / buffering 事件期间最多每 5 秒保存一次；暂停、跳转、切歌、队列修改与正常关闭立即保存。文件以 0600 权限写入 `.part`，完成后原子替换；保存失败保留旧文件、维持当前播放并向界面报告错误。

保存内容不包含音频媒体租约或请求头。封面租约转换回原图片地址，重启后按插件当前图片请求头生成新代理。启动时过滤已卸载来源的曲目；当前条目不可用时回退到保留下来的曲目并清零进度。损坏、版本不符、超过 8 MiB 或超过 1000 首的记录不加载。

恢复结果始终为 paused / wantPlay=false；启动不解析、不请求音频。用户按播放后使用保存进度重新解析当前曲目，进入原播放生命周期。重复歌曲保留各自条目 ID。清空队列后写入空记录，避免下次启动重新出现。

`GET/POST /api/preferences` 新增 `quality` 和 `source`，分别保存音质与浏览来源；合法音质为 `standard`、`high`、`lossless`，默认 `high`。解析时将偏好传给 `Source.Stream(id, quality)`，播放状态中的 `quality` 保留来源实际返回值。偏好变化不会重启当前音频，下一次解析生效；未保证所有来源或账号提供无损。

## 歌单编辑

沿用 `POST /api/sources/{instance}/call/{method}`，操作由来源 capabilities 和 `mine` / `fixed` 字段决定。仅自己的非固定歌单提供编辑入口；详情未返回 mine 时继承歌单列表的归属标记。

| 方法 | 请求字段 | 行为 |
| --- | --- | --- |
| `renamePlaylist` | `id`, `name` | 修改来源歌单名称 |
| `deletePlaylist` | `id` | 删除前确认，默认取消 |
| `removeFromPlaylist` | `id`, `trackIds` | 按上游协议移除歌曲 |
| `movePlaylistTrack` | `id`, `from`, `to` | 按从 0 开始的索引上下移序 |

写入失败保留页面和菜单，可重试。移除或移序成功后重新读取 `playlist`；如果写入成功但刷新失败，保留旧列表并暂时禁用依赖旧索引的编辑，显示“重新加载歌单”。刷新成功后回到操作附近的歌曲按钮。修改歌单不会重排、切换或重启现有播放队列。

## 电台持续播放

`POST /api/player/play` 可附带 `station: {source, id, name}`。Go 验证来源一致并具备 `stationNext`；remote 来源不启用本机连续电台。

当前歌曲及后续剩余曲目不超过 3 首时，后台调用 `Source.StationNext(id)` 补充元数据。每批最多接收 100 首可播放曲目；非空但全部不可用时最多请求 3 批。此过程不解析、不预下载后续音频。旧电台或退出电台之后的迟到批次丢弃。

电台按来源返回的顺序播放，保留普通队列原来的播放模式。队列最多 1000 首，接近上限时删除较早已播条目，保留最近 50 首、当前条目和未播歌曲。当前曲结束而下一批仍在获取时等待；等待期间暂停不会因补曲成功自动发声。空批次停止自动获取，错误保留已加载队列。

`POST /api/player/control` 支持 `station-retry` 和 `leave-station`。界面在队列中显示电台名、加载/错误/结束状态与重试、退出入口。退出连续电台保留正在播放的曲目、媒体租约与暂停状态，恢复普通播放模式入口。

## 播客节目分页

沿用 `show` 方法，参数为 `id` 和 `offset`，响应为 `ShowPage {show, episodes, more}`。首批 offset=0，后续按原始返回条数递增，而不是按去重后条数递增。按 source+id 去重；more=false、空批次或整批重复时终止加载。

接近列表底部时按需读取下一批，也保留“加载更多”按钮。追加 DOM 而非重画原列表；保留焦点、节点与滚动位置，主动点击加载后聚焦首个新增节目。失败保留已有节目，用相同 offset 重试。页面离开时取消请求并丢弃迟到响应，不改动已开始播放的队列。

## 验证范围

- Go race：真实服务重启与暂停恢复、重复条目、图片代理重建、卸载来源过滤、损坏记录、原子保存失败、来源与音质偏好持久化、电台补曲/失败重试/旧批次丢弃/重复结束/暂停/队列裁剪。
- Playwright：音质切换不打断播放、繁体界面、歌单编辑失败与刷新失败恢复、非本人及固定歌单、电台退出保留音频、播客懒加载/去重/取消/重试，以及子进程重启后不请求音频、按播放才从保存位置继续。
- 1280×720 截图检查音质设置、歌单操作、电台队列、追加后的节目列表；沿用完整焦点与多尺寸回归。异步页面响应保留用户在等待期间主动移动的焦点，同步返回仍恢复原控件。

Android 单元测试、lint、三 ABI 编译及 APK 完整性由私有仓库 CI 执行。浏览器及 CI 结果不替代 Android 6 实机、真实账号写入、真实电台长期播放或所有插件音质兼容性的验证。本轮未移植磁盘歌曲缓存、音量均衡、独立网页登录或 ffmpeg / yt-dlp / 桌面 helper。
