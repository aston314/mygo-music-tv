# 歌词逐字同步

来源提供完整、有效的 `lines[].words[]`（毫秒 `start/end`）时，当前行的字或词
随演唱进度渐亮，并最多放大 4.5%、上浮 1.8 个设计像素。中日韩歌词的精度由
插件提供的分字粒度决定，应用不会把整词时间伪装成真实逐字时间。

显示始终由播放位置推导：暂停和缓冲时冻结，恢复后继续，前后跳转直接重算；
切歌、退出页面、后台及歌词重绘时取消额外帧。只在当前词演唱期间请求动画帧，
额外绘制按约 40ms 一次调度，不重建歌词 DOM，不修改文字占位宽度或焦点。

现有显示作为自动兜底：

- 只有整行 LRC：保留整行变色、放大、居中滚动，不估算逐字时间。
- 某行缺少结束时间、时间倒序、非数值或文字不完整：该行显示完整文本，保留
  整行效果，其它有效行继续逐字同步。
- 无动画 API 或系统要求减少动态效果：保留原有整行与逐字切换高亮，停用渐亮
  和变换；无时间歌词继续静态展示及遥控滚动。

淡色与深色使用各自现有的歌词颜色。翻译保持整行，不生成逐字时间。
本次没有移植上游舞台模式的旋转、模糊、粒子或重发光。

回归覆盖见 `tests/lyric-effects.spec.cjs` 和 `tests/listening.spec.cjs`；物理电视
上的流畅度与真实插件歌词仍需在签名 APK 发布后验收。
