## 发现的问题与后续源码修复

v0.1.2 真机测试和用户反馈确认以下问题。后续源码修复不属于已发布的
v0.1.2 APK；不覆盖旧 Release 文件。

1. 底栏在专辑右移后再左移会回到歌手，未保留当前信息行。现在记住最后聚焦的
   歌手/专辑行，左右可往返，上下在两者之间切换；缺少详情能力时跳过禁用项，
   曲目信息变化导致当前项失效时恢复到可用项或封面。
2. 插件市场和设置原先仍显示播放栏。现在隐藏整栏、释放页面底部空间，同时
   从方向键路径移除隐藏控件，保留原生播放会话与媒体按键。
3. 歌词页歌手和专辑使用整列宽度焦点。现在短文字随内容收缩并保持居中，长文字
   在列宽内省略，沿用主题的通用焦点环。
4. 网易云拒绝某些播放请求时返回 `-460`，完整错误文字会撑破歌词页左侧时间轴。
   现限制时间轴的可收缩宽度，让错误文字在控制区内省略；此修复不解除上游拒绝。
