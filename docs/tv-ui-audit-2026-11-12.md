## 优先修复的交互问题

P1 表示可能误触账号操作；P2 表示会增加操作成本或形成死路。本轮没有执行退出账号来证明它的后果；直接调用退出接口这一点由当前源码确认。

### U01 · P1：查看账号后默认聚焦“退出账号”

- 复现：打开右上角账号或设置中的账号入口。TV 隐藏通用返回按钮后，窗口只有“退出账号”可聚焦，再按一次确认就会触发退出流程。
- 证据：`49-account-status.xml` 中唯一按钮为“退出账号”，`focused=true`。当前 `ui/app.js` 的 `login()` 仍采用此结构，`signOut()` 直接调用来源的 `signOut`，没有二次确认。
- 建议：提供明确的非破坏性“关闭”并默认聚焦；退出账号独立使用二次确认，写清来源和账号。可遥控返回并不能消除重复按确认的误触风险。
- 验收：打开账号后连续按确认不会登出；只有明确选择退出并确认后才调用接口。

### U02 · P2：播放顺序窗口没有聚焦当前选项

- 复现：选择单曲循环 → 重新打开播放顺序。单曲循环标有“当前”，焦点却回到顺序播放。
- 证据：`38-mode-selected-focus.png/xml`；当前 `modeMenu()` 未给弹窗传入当前模式的 `entry`。
- 建议：与音乐源选择一致，打开时聚焦当前模式；未选择时才用第一项。
- 验收：四种模式分别选中后重开，焦点与当前项一致，Back 不改变模式。

### U03 · P2：设置展示插件不支持的账号操作

- 复现：选李志来源 → 设置。仍有“账号 / 登录”“退出账号”；点击登录只提示“此音乐源没有提供登录”。
- 证据：`63-temp-source-settings.png`、`64-unsupported-account.png`；当前 `renderSettings()` 仍无条件生成这两个按钮。
- 建议：按 `account / signIn / signOut` 能力和登录状态显示入口。无需账号的来源给一行“无需登录”即可；未登录时不展示退出账号。
- 验收：无账号能力来源不出现无效按钮，有登录能力的来源根据状态变化。

### U04 · P2：加入歌单的空状态给出无法完成的指引

- 复现：歌曲更多操作 → 加入歌单。显示“暂无可加入的歌单，请先新建”，但网易云插件本轮未提供新建能力，窗口没有新建按钮。
- 证据：`59-add-playlist-ready.png`；当前 `loadPlaylists()` 固定使用这条空文案，新建按钮却受能力约束。
- 建议：有新建能力则显示并聚焦新建；无新建能力则说明需要先在音乐源官方应用创建歌单，并提供“重新读取”。不可将固定“我喜欢的音乐”当作普通可写歌单。
- 验收：空状态的建议有对应操作；没有可操作内容时不对整个窗口画红色焦点框。
