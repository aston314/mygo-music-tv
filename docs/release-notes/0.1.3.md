# MyGo Music TV 0.1.3

插件市场反馈、海报布局与歌词页修复。沿用已有签名，覆盖安装保留音乐源、登录、偏好与播放记录。

- 插件市场“检查全部更新”使用同步箭头，“刷新目录”使用目录图标；操作中显示旋转状态，成功或失败后恢复。忙碌期间阻止重复提交并保留遥控器焦点；刷新失败保留现有目录。
- 专辑、歌单、歌手、电台等海报网格按可见窗口切换列数：小于 1200px 为 3 列、1200–1599px 为 4 列、1600–2399px 为 5 列、2400px 起为 6 列。封面随卡片宽度保持正方形，窗口调整后保留当前焦点与滚动位置；插件卡不受影响。浏览器使用可见 CSS 视口，Android 使用实际 WebView 窗口宽度（非面板像素）选择列数，避免密度把 1080p 电视误判为小窗口；整体画布仍只按 CSS 视口连续等比缩放。
- 限制进度区的最小宽度与错误文字边界，网易云 `-460` 或其它长错误在区内省略，分栏/全屏歌词均不挤压歌词或进度条。此项处理错误展示，不解除音乐源拒绝。
- 底栏歌手/专辑支持左右往返并记住当前信息行；插件市场和设置隐藏播放栏、释放底部空间；歌词页信息焦点随文字长度收缩。

继续只提供在线音乐，不提供本地曲库。本版本仍通过私有 Release 分发，不新增公开下载镜像或应用内升级地址。
