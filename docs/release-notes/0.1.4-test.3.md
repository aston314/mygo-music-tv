# My Music+ 0.1.4-test.3

117 实机验收测试包，仅存放在私有草稿 Release，不进入公开更新渠道。沿用原签名和包名，覆盖安装保留数据，取代 test.2。

- 资源搜索、插件搜索均可扫码输入。手机提交后自动搜索，保留音乐源、资源分类与安装状态筛选；不自动播放、安装或切换来源。
- 输入框按 Down 到搜索按钮，再按 Right 到扫码入口，保留输入时左右移动光标的功能。
- 修复首次专辑、歌手等搜索返回可分页数据时，焦点错误跳到“加载更多”并滚至底部的问题；首次搜索聚焦第一条结果。
- 包含 test.2 的插件中断回传修复，以及新图标、逐字歌词兜底、旋转圆形封面和插件市场交互更新。

构建校验 Go race、浏览器回归、Android 单元测试、Release lint、签名及三个 ABI。实体设备结果另见验收报告。
