# MyGo Music TV 0.1.0

首个 Android TV 安装测试版本。固定 1280×720 逻辑画布，支持 Android 6 及以上，APK 包含 arm64-v8a、armeabi-v7a 和 x86_64 三种核心。

- 官方插件目录、自动安装和更新、国内下载代理与直连回退。
- 在线音乐搜索、歌单、歌手和专辑浏览、喜欢、评论、电台和播客，按来源实际能力提供。
- 歌词、播放顺序、播放恢复、音质设置、遥控器焦点、淡色/深色主题及简繁中文。
- 扫码、原生临时网页登录、Cookie 回传和本机 OAuth 回调。
- 插件市场和设置页隐藏右上角账号；插件说明不再包含官网的“安装 GitHub”操作文字。

安装：从本私有 Release 下载 APK，复制到电视或通过 ADB 安装。文件和签名验证信息见 SHA256SUMS.txt 与 update.json。本轮没有配置匿名公开下载仓库或应用内自动升级地址。

验证范围：CI 编译、Go/浏览器/Android 回归不能代替真实账号或电视实机。62 项目录中 56 项安装检查通过，31 项返回非空搜索结果、7 项取得 HTTP 音频地址；这不代表所有插件均能在电视播放。部分来源需要账号、外部设备或额外平台适配。本应用不提供本地曲库，不启动 ffmpeg、yt-dlp 或桌面 helper。
