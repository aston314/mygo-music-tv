# MyGo Music TV 0.1.2

界面适配与封面修复版本。沿用既有发布签名，可覆盖安装并保留音乐源、登录、设置和播放记录。

- 以 1280×720 为最小逻辑画布，连续等比缩放并扩展画布，铺满非 16:9 窗口；窗口变化后校正当前焦点和歌词位置。
- Android TV 使用明确的平台标识，隐藏纯导航返回按钮与滚动条；桌面浏览器保留返回按钮。遥控器返回、列表滚动和弹窗取消保持可用。
- 歌词页移除“正在播放”标题及重复的翻译开关，歌词翻译统一从设置控制；TV 歌词区域使用腾出的顶部空间。
- 统一账号、导航、菜单、主题选择和播放按钮的图文对齐；调整播放三角形位置、状态文字与进度区域间距。
- 海报下的专辑增加“专辑 · ”标识；歌手和专辑入口使用通用焦点样式，长文字不裁切焦点环。
- 修复播放队列封面地址在 30 分钟后失效的问题。当前封面保留，后续歌曲封面被淘汰后可重新登记；图片请求使用当前插件图片头。
- 大小播放封面失败时显示 SVG 占位并有限重试，旧歌曲回调不覆盖新封面，不重启播放或改变焦点。

保持在线音乐模式，不提供本地曲库。封面改进是图片地址保留策略，并非迁移上游整套原生位图缓存。Android 6 及其它 TV 平台仍需对应设备验证。
