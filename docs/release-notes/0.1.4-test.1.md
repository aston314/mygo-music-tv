# My Music+ 0.1.4-test.1

117 设备验收用签名测试包。仅保存在私有草稿 Release，不进入公开下载或应用更新渠道；沿用已有包名与签名，覆盖安装保留原有数据。

- 资源搜索与插件搜索增加“扫码输入”。手机与电视在同一局域网时，扫码填写关键词并点击搜索，电视自动搜索并定位结果。保留音乐源、资源分类与插件筛选，不自动播放或安装。
- 扫码连接五分钟有效，支持取消、刷新、返回和后台撤销，旧二维码与迟到结果失效。原有键盘输入保留；搜索失败可保留文字重试。
- 更新 My Music+ 应用图标及启动图标，侧栏标志跟随主题。
- 有完整逐字时间戳时歌词随播放进度渐亮、轻微放大，缺失或无效时继续使用原有整行同步显示。
- 底部圆形封面在播放时缓慢顺时针旋转，暂停时停止；增加歌名、歌手、专辑之间的焦点间距。
- 优化插件搜索与安装状态筛选、设置分组、空结果引导、账号退出确认和弹窗焦点。

签名与三 ABI 检查、Go race、JavaScript 和浏览器回归由构建工作流执行。实际设备结果另记验收报告。
