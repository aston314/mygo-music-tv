# My Music+ 0.1.4-test.2

117 设备验收用签名测试包，仅保存在私有草稿 Release，不进入公开下载或应用更新渠道。沿用已有包名与签名，覆盖安装保留数据。此包取代未安装的 test.1。

- 资源搜索与插件搜索支持同一局域网内扫码输入，手机点击搜索后电视自动搜索并聚焦结果，保留来源、分类或插件筛选。支持取消、刷新、后台失效与搜索失败重试，原有键盘输入保留。
- 包含 My Music+ 新图标、逐字歌词效果和原有整行显示兜底、底部旋转圆形封面、信息间距与插件市场操作体验更新。
- 修复插件调用刚回传结果时遇到退出中断，可能重复回传并阻塞运行时退出的问题。相同触发条件的回归测试验证只回传一次，并正确回收调用状态。

构建执行 Go race、浏览器回归、Android 单元测试、Release lint、签名和三 ABI 校验。实体设备验收另行记录。
