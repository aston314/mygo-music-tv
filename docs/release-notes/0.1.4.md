# My Music+ 0.1.4

把喜欢的音乐，带到电视大屏。

- 正式使用 My Music+ 名称和新图标；启动时加号轻轻转动，加载状态更直观。
- 在插件市场发现、搜索、安装和更新在线音乐源；区分已安装与未安装，官方目录不可用时使用公共目录兜底。
- 音乐搜索与插件搜索均支持手机扫码输入，减少遥控器打字。
- 音乐源提供逐字时间时，歌词随演唱逐字高亮；普通同步歌词继续作为兜底。
- 底部封面以圆形展示，播放时缓慢旋转；调整歌名、歌手、专辑间距及文字焦点宽度。
- 优化卡片标题折行、歌单文字大小、海报外侧焦点间距与焦点移动；淡色主题排在深色主题之前。
- 用户入口通过小点显示登录状态；支持开发入口与用户入口同色、同时显示或隐藏。
- 设置新增版本更新，下载经校验后交给系统安装；优化更新区间距、扫码弹窗焦点和退出确认按钮。

适用于 Android 电视与电视盒子，最低 Android 6.0。沿用原包名和发布签名，覆盖安装保留现有数据。旧版 0.1.3 需先手动安装本版本，之后可在“设置 → 版本更新”检查后续更新。

音乐内容、登录方式、歌词、评论等能力由所选插件提供；部分内容需要对应平台账号或会员权限。网易云部分请求仍可能返回 -460，本版本不承诺消除平台风控。

感谢 MyGo Music、EGOIST 及插件作者与贡献者。
