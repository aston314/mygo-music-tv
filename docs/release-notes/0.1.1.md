# MyGo Music TV 0.1.1

电视实测修复版本，沿用 0.1.0 签名，可直接覆盖安装并保留已有数据。

- 修复 Android TV WebView 将溢出内容宽度计入 innerWidth 后造成的画布放大、右侧和底部裁切；1280×720 逻辑画布按实际可见区域等比缩放。
- 首次安装内置最近一次完整官方插件目录。先显示全部 62 个来源并标记目录状态，后台继续抓取官网；官网超时后仍可选择和安装来源，也可手动刷新。目录仅代表收录，不代表运行或播放验证。
- 设置和启动页版本号改为读取应用配置，避免版本标签写死。

继承插件说明清理、插件市场和设置页隐藏账号信息、在线音乐、歌词、遥控器控制、简繁中文与主题设置。不提供本地曲库，不执行桌面专用程序。
