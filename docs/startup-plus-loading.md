# 启动页：Logo 加号加载动画

2026-11-15，用户确认以 Logo 内的加号旋转取代外部加载圆环。这是本产品的品牌设计例外；仍沿用 Logo、启动状态、版本号三行居中及真实就绪信号驱动的启动流程。

- 红色圆底与白色音符固定，只有右上角白色加号绕自身中心顺时针匀速旋转，周期 3000ms。
- 沿用原始 SVG 的轮廓、坐标和尺寸；保留 Logo 的固定布局槽位，动画不参与焦点、不改变布局，也不表示百分比。
- Web 启动页用独立 SVG 分组和 CSS transform，旋转原点为原始坐标 `(72,32)`；无需 `transform-box`、SMIL 或额外动画库。
- Android 原生启动页使用 `startup_logo_base.xml` 绘制静态圆底／音符，用 Canvas 按同一坐标与变换绘制加号。后台不可见时不持续请求动画帧。
- 成功就绪时停止动画并进入主界面，不等待动画转完一圈。启动请求失败时停止动画、加号恢复正立、聚焦“重试”；重试恢复状态文字和动画。
- Web 启动失败通过受信任页面的 `Android.startupFailed()` 移除原生遮罩，露出网页错误与重试按钮；这不会把应用标记为就绪，也不会启动更新检查。成功仍由 `uiReady()` 完成。
- 系统桌面启动图标、应用内侧栏品牌图标使用原有静态资源。

- 覆盖 health、config、preferences、sources 四阶段的失败、停止、默认焦点、遥控器 Enter 重试和成功就绪通知。
