# Android 6 深色焦点与侧栏性能

2026-11-15，154（ZIDOO X9S、Android 6.0.1、系统 WebView 44.0.2403.119）实机截图显示：海报使用自己的圆角外框，普通控件的深色主题 `outline` 却显示成方框。问题影响导航与设置等共用通用焦点的控件。

通用深色焦点改用无模糊的两层 `box-shadow`，保留 3px 间距及薄荷色外环，跟随控件本身的圆角；继续由 `:focus` 控制，鼠标、键盘、遥控器共用。浅色规则、海报及进度条自己的焦点规则继续生效。

导航按键原来先对整个应用调用 `focusables()`，每个内容项都读取 `getClientRects()`，随后才按侧栏的上下顺序移动。现将侧栏路由提前，只读取侧栏及目标控件；按 ID 恢复焦点也只测量匹配项，区块内查询只遍历所在区块。保留原有方向、边界、滚动与返回目标。

同一次 Chromium 测量，1920×1080、6 倍 CPU 降速、500 个示例海报、48 次侧栏上下键：

| 指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 内容区矩形读取 | 24,000 | 0 |
| 总矩形读取 | 25,104 | 144 |
| 按键处理耗时中位数 | 2.2 ms | 0.1 ms |
| 按键处理耗时 P95 | 4.6 ms | 1.1 ms |

这是开发机浏览器的同场景比较，不代表 Android 6 的实测耗时或电视帧率。原始记录位于忽略目录 `build/nav-baseline.json` 与 `build/nav-optimized.json`。新增行为检查覆盖深色两种侧栏模式、设置圆角焦点、500 卡片下的侧栏路由及无内容区布局读取；其余焦点和主题测试继续回归。
